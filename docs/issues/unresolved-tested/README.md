# Unresolved, unit-tested issues

Open problems whose **rule** has a passing xUnit test, but which are
**not** confirmed in the running game.

Status is this folder: `Status: unresolved-tested` in the file. Move
here from `unresolved/` when the tests pass. Move to `resolved/` only
after in-game confirm — same rule as always
([`../README.md`](../README.md)).

A green test means the helper behaves. Harmony binding, Unity
fake-null, FadeScreen, and audio can still fail in Steam/Proton.

Process and naming: [`../../roadmaps/completed/test-suite.md`](../../roadmaps/completed/test-suite.md).
